# 阶段二：数据生产管线、训练/验证划分与训练可视化 Spec

## Why

阶段一完成模型架构重构（参数 4.36M→0.689M、五路物理损失、4 轴可学习 RoPE），但仅做过 4 样本冒烟训练，存在四个断层：① 改进效果无量化证据（无基线对比、无系统评估指标）；② `train.py` 只能读单工况目录（14 对），全量 1314 对无法加载，无训练/验证划分；③ 现有真值场生成方法未知、未经独立验证（用户要求"场一定要确保计算正确"）；④ 数据量是否足够、能否拓展到不规则区域没有答案。

## 数据勘察事实（2026-10-01 实测，本 Spec 的裁决依据）

> [!info] 全库结构（99+ 工况目录实测）
> - **组织**：`retangle_data/results_reduction_fixed_boundary{2..100}` + 默认目录，~100 个工况；每工况 11–14 个高度变体（后缀第二数字 = 区域高度 px：256→166 步进 -10，个别含 50），**合计 ~1314 对**
> - **几何构型**：外框源极（1px 环，0V）+ 空气域内散布 **1–10 个实心矩形 HV 电极**（60000V）。源极连通域分布：1 域=64 工况（仅外框）、2 域=20、3 域=15（含内部源极条带）；3 个工况（13/15/16）HV 电极含闭合空腔
> - **变体维度**：工况编号 = 电极数量/位置布局；后缀 = 区域高度（垂直压缩），宽度恒 256
> - **适定性**：空气被 Dirichlet 边界完全包裹（air 触边 = 0 全库成立）→ 无 Neumann 歧义，问题适定

**真值场质量抽查（8 工况）**：源极电位恒 0V、HV 恒 60000V **精确**；导体内 E=0 **精确**（存储常数）；空气区离散 Laplace 残差 max 1.0–7.5V（相对 Vmax 1.7e-5 ~ 1.3e-4），**非零** → 不是本网格 5 点 FD 直接生成（可能来自细网格降采样/解析级数/FEM），物理自洽度高但需独立求解器交叉验证方可出具"正确"证书。

**当前数据组织的不合理处（需修复）**：
1. `ElectrostaticDataset._find_file_pairs` 仅平铺 glob 单目录 → 根目录指向 1314 对时读到 0 对（**全量训练的阻断性缺口**）
2. 无划分、无验证集、无 condition（工况）元数据 → 无法评估泛化与防泄漏

## What Changes

- **新增** 多工况递归数据加载（condition 元数据 = 工况目录名）
- **新增** 训练/验证划分：random 分层与 group 工况级两种模式 + manifest 可复现
- **新增** 评估指标模块 `eval_utils.py`：相对 L2、最大误差、BC 违反度、Laplace 残差、等位残差（masked 口径与训练一致）
- **新增** TensorBoard 训练可视化扩展：per-epoch 验证指标、验证样本四联图（region/target/prediction/error）、误差直方图、run 命名与 hparams（支撑 v1/v2/未来阶段对比）
- **新增** 独立 FD 求解器 + 全量 1314 对交叉校验报告 → 现有数据"合理性裁决"
- **新增** v1 基线复现（从旧权重 state_dict 反推架构 `model_v1.py`）与零样本对比
- **新增** 自动化数据生成脚本 `gen_data.py`（多几何族参数化 + 自动校验拒写盘）+ 新几何族数据集（`/workspace/data/<几何族>/<工况>/`）
- **新增** 数据量学习曲线实验 + 讨论文档
- 无 **BREAKING**：所有 CLI 新参数均有默认值，旧调用行为不变（除 data-path 语义扩展为"目录或根目录均可"）

## Impact

- Affected specs: 阶段一 `improve-model-architecture`（其"阶段二展望"项由本 Spec 承接）
- 依赖环境：沙箱已重置，需重装 torch(cpu)/tensorboard/matplotlib

## ADDED Requirements

### R1: 多工况递归数据加载

系统 SHALL 支持把 `--data-path` 指向数据根目录，递归发现所有子目录中的 `original_region_data_*.csv` / `potential_distribution_*.csv` 配对，并为每对样本附 condition 元数据（相对父目录名）。

#### Scenario: 根目录全量加载
- **WHEN** `--data-path /workspace/retangle_data`
- **THEN** 数据集发现 ~1314 对，覆盖全部工况目录；condition = 样本所在工况目录名

#### Scenario: 旧路径回归
- **WHEN** `--data-path` 指向单个工况目录（如默认目录）
- **THEN** 行为与阶段一完全一致（仅该目录样本对）

### R2: 训练/验证划分

系统 SHALL 提供两种可复现划分模式，并将划分写入 manifest JSON（含 seed、模式、train/val 文件清单与 condition 标注）。

- **random 模式（默认）**：按样本 80/20 随机，按 condition 分层（每工况 val 样本数 ≥1，工况样本不足时保证仍可训练）
- **group 模式**：按工况整组 80/20，val 工况与 train 工况零交集（未见构型外推评估）

#### Scenario: 可复现
- **WHEN** 相同 `--split-seed` 与相同数据再次划分
- **THEN** manifest 与成员完全一致

#### Scenario: group 防泄漏
- **WHEN** group 模式划分后
- **THEN** 任一 condition 的样本只出现在 train 或 val 一侧

### R3: 评估指标模块

系统 SHALL 在 `eval_utils.py` 提供 masked 口径指标：相对 L2（‖φ−φ*‖₂/‖φ*‖₂）、最大绝对误差、BC 违反度（源极∪边界处 max|φ−φ*|）、Laplace 残差（空气区十字内点 mean|∇²φ·H²|）、等位残差（导体内点 mean|∇φ|·H）。供训练验证循环与独立评估 `eval.py` 复用。

#### Scenario: toy 已知解验证
- **WHEN** 用解析可验证的 toy 张量（如线性电位场，∇²φ=0）调用指标
- **THEN** 各指标返回与手算一致（Laplace 残差 = 0，相对 L2 = 0 当 pred=target）

### R4: TensorBoard 训练过程可视化

系统 SHALL 在训练时记录：
1. **训练过程**：五路损失分项 + 总损失（已有）+ RoPE 16 频率（已有）+ per-epoch 验证指标（R3 全部指标）
2. **样本可视化**：每 `--vis-interval` epoch 记录 K 个验证样本的四联图（区域图/目标/预测/|误差|）与误差直方图
3. **跨阶段对比**：`--run-name`/`--tag` 与 hparams（全部超参 + 数据量 + 划分模式）→ TensorBoard 中 v1 基线、v2、未来阶段同口径可比

#### Scenario: 体现改进效果
- **WHEN** v2 训练完成并运行 v1 零样本评估（同 val split、同指标、同 run 命名规范）
- **THEN** TensorBoard 可并排对比两者 val 相对 L2 等指标曲线/标量

### R5: v1 基线复现与对比

系统 SHALL 从 `dual_encoder_fno_model.pth`（17MB 旧权重）的 state_dict 键名与形状反推 v1 架构，实现 `model_v1.py` 并严格加载旧权重（无 missing/unexpected keys），在阶段二验证集上零样本评估，与 v2 同口径对比。

#### Scenario: 权重加载
- **WHEN** `model_v1.py` 加载旧权重 `load_state_dict(strict=True)`
- **THEN** 成功且评估出全套 R3 指标

### R6: 现有数据真值场验证与裁决

系统 SHALL 实现独立 FD 求解器（5 点差分 + 稀疏直接/CG 求解，Dirichlet 全封闭，收敛残差 < 1e-10 相对），对全量 1314 对执行交叉校验并产出报告（每对：相对 L2、max 误差、BC 精确性、E=0、存储场自身 Laplace 残差），最终给出裁决：
- **PASS**（数据合理，按当前逻辑生成新几何族）：独立解与存储场相对 L2 < 1e-3 且 BC/E=0 精确
- **FAIL**（给出新方案并按新方案重建数据对）

#### Scenario: 交叉校验
- **WHEN** 对 boundary2/0_256 运行 FD 求解并与存储场对比
- **THEN** 相对 L2 在离散误差量级内（预期 ~1e-4，阈值 1e-3），报告记录两解 max 差

### R7: 自动化数据生成管线

系统 SHALL 提供 `gen_data.py`：参数化几何族 → 区域图 → FD 求解电位 → 导体区写常数 → 写 CSV 对，且**每对数据落盘前必须通过自动校验**（BC 精确、导体内 E=0、空气 Laplace 残差 < tol、与第二方法抽检一致——细网格求解降采样或不同求解器）；校验失败拒写盘并报错。输出布局 `/workspace/data/<几何族>/<工况名>/`，文件命名兼容 R1 递归扫描。

#### Scenario: 校验拦截
- **WHEN** 某对数据的 FD 解未收敛（残差 > tol）
- **THEN** 该对不写入磁盘，脚本记录失败原因并以非零退出码结束

### R8: 新几何族数据集

在 R6 裁决为 PASS 的前提下，SHALL 按当前数据逻辑（外框源极 0V + 内部 HV 电极 60000V + 空气域）生成新几何族数据：矩形补充族 + 圆/椭圆族 + 直线多边形族（L/T/U）+ 随机 blob 族（傅里叶扰动半径），各族全部通过 R7 自动校验。

#### Scenario: 目录组织
- **WHEN** 生成完成
- **THEN** `/workspace/data/` 下按族分子目录，dataset 递归加载可读出全部新对，抽检指标通过

### R9: 数据量学习曲线与讨论文档

系统 SHALL 用 25%/50%/75%/100% 训练子集（同验证集、同超参）各训练一次，产出"val 相对 L2 vs 训练样本数"曲线写入 TensorBoard，并产出讨论文档（proceedings）：每几何形状所需样本数建议、总数据量结论、不规则区域拓展路线。

#### Scenario: 学习曲线
- **WHEN** 4 个子集训练完成
- **THEN** TensorBoard 出现 4 点对比曲线，讨论文档给出"当前 1314 对是否足够、缺口多少"的实证结论

## 数据量讨论（回答用户问题 3，实施期由 R9 实证修正）

### 现状与量纲
- 现有 ~1314 对 = ~100 构型 × ~13 高度变体，全部属"矩形电极-外框"单一宏族；模型 0.689M 参数
- **多样性瓶颈在构型数而非总对数**：高度只是 1 维参数变化，电场形态主要由电极数量/位置决定

### 需要多少数据（三层框架）
1. **构型多样性**（最重要）：每几何族 ≥ 50–100 个"电极构型"（数量、位置、尺寸随机采样）
2. **参数变体**：每构型 5–15 个参数变体（高度/比例/位置抖动）→ 每族 500–1500 对
3. **PINN 折减**：loss_bc/loss_eq 不依赖真值、Laplace 残差纯物理 → 标签需求低于纯数据驱动；保守可按上界准备，由学习曲线裁剪

### 实证判据（R9）
- 学习曲线边际收益法：样本翻倍后 val 相对 L2 改善 < 10% 即"够用"；外推口径（group split）另评
- 当前 1314 对的矩形族预计已接近饱和（100 构型），**缺口在"族多样性"**（圆/多边形/blob 全空白）

### 如何拓展到复杂不规则区域
- **模型侧无需改动**：4 轴 RoPE 的 EDT 距离轴、物理损失（PDE/BC/等位）天然几何无关；FNO+注意力对边界形状不敏感
- **生成侧分形课程**：矩形（已有）→ 直线多边形（L/T/U，电极也可非矩形）→ 曲线边界（圆/椭圆电极）→ 随机 blob（极坐标傅里叶扰动半径 r(θ)=r₀(1+Σ aₖcos(kθ+φₖ))，幅度限幅保证不自交）→ 多电极混合
- **关键风险与对策**：训练分布外的极端形状 → group split 单独报告外推误差；细颈/尖角几何的 FD 求解精度 → 生成器校验时用细网格抽检兜底

## 对用户问题 5 的补充建议（已并入上述需求）
