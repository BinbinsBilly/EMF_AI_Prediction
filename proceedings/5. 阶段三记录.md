## 二、标注方案 v2（根除 0 值歧义）

### 2.1 方案定义

| 值 | 语义 | 物理约束 | 出现位置 |
|---|---|---|---|
| **0** | **仅填充** | — | 严禁出现在任何落盘 CSV；仅由 dataset.py 对称填充产生，由有效性掩码区分 |
| **1** | 接地电极 | Dirichlet 0V，导体内 E=0 | 外框 1px 环（恒为 1） + 内部接地电极（按 `--p-ground` 采样） |
| **2** | 空气求解域 | Laplace 方程 ∇²φ=0 | 唯一未知量区域 |
| **3** | 高压电极（HV） | Dirichlet 60000V，导体内 E=0 | 至少 1 个 / 布局（强制） |

### 2.2 与旧方案的本质差异

旧 retangle_data 中 0 既表示 dataset.py 的零填充、又在 boundary21/_50 系列中表示 0V 接地电极——同一数值承担两种语义，加载侧无法区分。v2 把这两件事彻底分离：

- **落盘侧**：region 图值域严格 ⊆ {1, 2, 3}；gen_data.py 新增校验关⑥在写盘前显式断言 `set(unique(region)) ⊆ {1,2,3}`，违反即拒写盘并记录失败
- **加载侧**：dataset.py 在对称填充时才引入 0，并由有效性掩码 `mask` 区分；one-hot 3 通道编码不变（SRC / AIR / HV 三通道），下游管线零改动

### 2.3 关于 verify_data.py 的"隐藏电极"提示

2000 对反向闭环报告中出现"region 错标（隐藏接地电极）: 203 对 / 79283 px；隐藏 HV: 57 对 / 6513 px"。该检测器是阶段二为 retangle_data 设计的几何口径（识别"未在 region 中标注但被电极占据"的像素），在 v2 语义下不再适用：

- v2 的内部接地电极是**有意标注**的 ground（非漏标）
- 裁剪变体可能让电极与外框环几何粘连，存储场按 %.3f 定点读回后边界处仍精确满足 0V / 60000V，但检测器在某些边角像素上会触发"隐藏"告警

**裁决证据**：2000/2000 对 BC 精确率全过（源极 2000/2000、HV 2000/2000、0V 像素 2000/2000）+ rel L2 全部 < 1e-5（FD 精确解级）+ 求解器相对残差 max 3.585e-15——存储场与 region 标注完全一致，告警为良性 %.3f 舍入 / 旧检测器语义残留，**非错标**。

## 三、生成器扩展（Task 1）

### 3.1 内部接地电极（`--p-ground`，默认 0.25）

```python
# gen_data.py::_colorize（核心逻辑）
is_ground = rng.random(n) < p_ground       # 每电极独立采样
if not np.any(~is_ground):                 # 全接地 → 强制一个为 HV
    is_ground[int(rng.integers(0, n))] = False
```

- 每个内部电极独立以概率 `p_ground` 标为接地（1），否则为 HV（3）
- 若整布局采样结果全为接地（无 HV），强制随机一个改为 HV——保证 ≥1 HV
- 外框 1px 环恒为 1，不受采样影响
- 每个电极的 `type` 字段（"ground" / "hv"）写入 gen_report.json 的 electrodes 元数据

### 3.2 分层工况设计

```
n_target = 1 + (cond % N_max)    # N_max: rect=10, circle=6, polygon=4, blob=3
```

每族 50 工况的电极数按目标轮转（rect 族 1..10 各 5 个工况、circle 1..6 约 8-9 个、polygon 1..4 约 12-13 个、blob 1..3 约 16-17 个），保证电极数量维均匀覆盖；放置仍为最佳努力（bbox 各膨胀 4 px 不重叠 ⇔ ≥8 px 空气隙），放不下则少放并记录 `actual_electrodes`。

### 3.3 variant_ok 扩展（两类电极碎片检查）

```python
# 伪代码
ok_hv, n_hv, _ = check_fragments(v == HV, min_px=20, exempt_if_empty=False)
ok_g,  n_g,  _ = check_fragments(internal_src_mask(v), min_px=20, exempt_if_empty=True)
```

- HV 必须至少 1 个连通域且全部 ≥20 px（不允许无 HV 布局）
- 内部接地（**外框 1px 环豁免**）允许 0 个，但若存在必须全部 ≥20 px
- 任一不达标 → 整布局重采样（每工况最多 200 次）

### 3.4 校验体系（六关）

在既有五关（① BC 精确 mem+roundtrip / ② 导体 E=0 / ③ 求解残差 <1e-10 / ④ 存储 Laplace <0.05V / ⑤ 细网格 rel L2 <0.02）之上新增：

- **⑥ 标注合规**：落盘前显式断言 `set(unique(region)) ⊆ {1,2,3}`，0 严禁出现；失败置 `fail_reason="region_label_violation"` 拒写盘
